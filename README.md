# Pranjit Malakar — Personal Portfolio

A premium dark personal portfolio with charcoal surfaces, restrained gold accents and responsive layouts.

## Sections
- Introduction and professional positioning
- About and career highlights
- Professional experience
- Selected work: GORAV OS and digital community building
- Skills, education and languages
- Contact

## Run locally
This is a static website. Open `index.html` in a browser, or serve this folder with any static file server.

## Deploy
Connect this repository to Cloudflare Pages. Use the repository root as the project directory. No build command is required; set the output directory to `/` (or leave the static-site root configuration as instructed by Cloudflare Pages).

## Before publishing
- Add the approved profile photo as `profile.png` and replace the placeholder in `index.html`.
- Confirm phone/email and public social links.
- Confirm experience dates and metrics.
- Add a public GORAV OS demo link if desired.

## Tech
HTML, CSS and vanilla JavaScript. No framework or paid dependency required.
